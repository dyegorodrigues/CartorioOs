# STUDENT MATERIAL FORMAT V2 — C01 calibration
**Status:** active candidate format

## Principle
The student-facing material must feel like a premium, structured study edition, not engineering documentation.

## Topic template

### 1. Title
Use the same curricular title/order as DD unless an explicit audited reordering improves prerequisite flow.

### 2. EM 1 MINUTO
5–10 lines maximum.
Purpose:
- orient;
- preview nomenclature;
- create a scaffold.

Not enough for study alone.

### 3. Teaching body
Use the best representation per concept:
- prose for causal/logical explanation;
- high-density table for relations/comparisons;
- timeline for history;
- flow for sequence;
- law box for literal norm;
- callout for exception/confusion.

### 4. Strategic table rules
A table may replace prose when it is self-sufficient.
Each row should preserve:
- exact exam nomenclature;
- alias in same label when possible;
- meaning;
- distinction;
- example/author/exception when useful.

Do not compress merely to shorten.

### 5. Cognitive hyperlinks
Short inline reconnections:
- prior concept;
- article;
- principle;
- author;
- future topic.

They must clarify, not interrupt.

### 6. Callouts
- ATENÇÃO
- NÃO CONFUNDA
- CAIU
- COMPLEMENTO
- DELEGADO+
- RECONEXÃO

Every callout must have a pedagogical function.

### 7. Progressive questions
Immediately after each topic.

Question families:
- opening definition;
- parent reconstruction;
- precision child;
- contrast;
- application/C-E.

Answers:
- direct answer first;
- explanation after;
- optional quick-answer cue.

### 8. Chapter closing
- ultra-fast map;
- Passo-like mother questions;
- real exam lab;
- authored C/E from real distractor mechanisms;
- oral/discursive output.

## Source model
- Gran: editorial/didactic grammar.
- DD: curriculum/depth.
- Legis/Juris: normative/case-law integration.
- Passo/Brainscape/MRC: active recall engineering.
- Official exams: sufficiency and distractor QA.
- Official law/courts: authority/freshness.

## Non-negotiable
No student-facing heading such as:
- “Claim graph”
- “atomic matrix”
- “answer_scope”
- “tree first”
- internal QA jargon.

Those remain backstage.
