# Protocolo de Calibração de Estilo de Pergunta/Resposta — V1

## Objetivo
Descobrir empiricamente quais formatos geram mais fluidez para o usuário sem confundir “preferência visual” com qualidade jurídica.

## Não será feito agora
Não interromper a pesquisa pedindo ao usuário para escolher entre dezenas de decks.

## Quando aplicar
Após o C01 possuir:
- árvore curricular auditada;
- pelo menos 5 famílias de fonte lidas;
- perguntas candidatas boas por função;
- teoria-base suficiente para conferir respostas.

## Calibration Set
Montar 8 a 12 pares/trios sobre **o mesmo conteúdo jurídico**.

Cada conjunto compara, por exemplo:

### A — Passo-like
Pergunta-mãe + resposta explicativa contínua.

### B — Brainscape estruturado
Pergunta direta + bullets/subitens.

### C — Tabela estratégica
Pergunta + resposta relacional em tabela.

### D — Duas velocidades
Resposta comentada + “resposta-relâmpago”.

### E — MRC/Trutas
Assertiva C/E + comentário de prova.

### F — Caso/aplicação
Mini-situação + resolução comentada.

O conteúdo técnico deve ser equivalente entre variantes; mudar somente a forma.

## Avaliação simples
O usuário poderá marcar:
- **fluidez**;
- **clareza**;
- **densidade adequada**;
- **vontade de continuar estudando**;
- **revisabilidade**;
- observação livre.

Não pedir nota para tudo se isso gerar atrito. Preferir comparação A/B/C e comentário espontâneo.

## Saída
Gerar um perfil editorial, por exemplo:
- 45% pergunta-resposta explicativa;
- 25% tabelas;
- 15% C/E comentado;
- 10% mini-caso;
- 5% resposta oral/discursiva no primeiro ciclo.

Esses percentuais são configuração inicial, não dogma.
