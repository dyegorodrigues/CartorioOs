## Editorial conclusions for the DEMO
1. Teach control as a decision matrix, not a catalogue: moment -> route -> object -> parameter -> legitimate -> effect -> quorum.
2. Treat ADPF object/temporality/subsidiarity, art. 103 legitimacy, art. 97/SV10, art. 27 modulation and state control as discriminative nodes.
3. Explicitly separate `rescisory of the objective ADI/ADC judgment` from `rescissory challenge to an earlier individual judgment`.
4. Keep state control connected to cartorial ENAC applications.
5. Separate bank-style evidence from domain-incidence evidence.
6. Material layers should derive from one semantic unit: MASTER -> REVIEW -> RECALL -> EXAM.
