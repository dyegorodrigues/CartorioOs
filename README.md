# GX Cartório OS

Sistema operacional pessoal de preparação para ENAC e concursos de delegações notariais e registrais.

## Objetivo
Levar o candidato do estado inicial de conhecimento enferrujado ao domínio verificável do conteúdo nacional e dos overlays estaduais, com material didático canônico, engenharia reversa de provas, tutoria adaptativa, revisão, simulados, discursiva, peça prática e oral.

## Regra central
**Chat não é memória e leitura não é domínio.**

- ChatGPT = tutor/orquestrador.
- Notion = material mestre + estado operacional do estudo.
- GitHub = arquitetura, protocolos, pesquisas versionadas, schemas e workflows.
- Fontes oficiais = autoridade jurídica primária.
